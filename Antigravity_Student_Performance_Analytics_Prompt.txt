ANTIGRAVITY MASTER PROMPT
=============================

PROJECT: STUDENT PERFORMANCE PREDICTION ANALYTICS
PURPOSE: HACKATHON FUNCTIONAL PROTOTYPE

You are an expert full-stack developer, ML engineer, UI/UX designer, and software architect.

Build a functional, polished, hackathon-ready web application called:

"Student Performance Prediction Analytics"

PROJECT OBJECTIVE
-----------------
The system should identify students who may be at risk of underperforming early so teachers can intervene before the problem becomes serious.

Core flow:

Student Data
    ↓
Data Processing
    ↓
Feature Engineering
    ↓
ML Prediction
    ↓
Risk Score
    ↓
Explainable Insights
    ↓
Teacher Dashboard
    ↓
Alerts + Recommendations

This is a prototype for a hackathon. Prioritize reliability, working features, good UI, realistic demo data, explainability, and a smooth 3–5 minute demonstration.

Do not over-engineer the project.

9. RISK CALCULATION

Create a transparent prototype calculation.

Suggested weights:
- Attendance: 25%
- Academic performance: 30%
- Assignment completion: 15%
- LMS engagement: 15%
- Participation: 10%
- Behavioral indicator: 5%

Normalize values before calculating.

Risk score:
0–39 = LOW RISK
40–69 = MEDIUM RISK
70–100 = HIGH RISK

Keep thresholds and weights configurable.

If a trained ML model is available, use ML prediction instead of the fallback calculation.

Do not claim mock calculations are real ML.
